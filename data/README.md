# Données

Le fichier de données n'est pas versionné dans ce dépôt.

1. Télécharger le jeu **Monthly Electricity Data** d'Ember (format long, fichier `monthly_full_release_long_format.csv`) :
   https://ember-energy.org/data/monthly-electricity-data
2. Le placer dans ce dossier : `data/monthly_full_release_long_format.csv`.

Variable utilisée : `Area == "Germany"`, `Variable == "Demand"` (TWh, fréquence mensuelle).
